# napari-msi-superpixels
Dedicated importer for MSI data to correct order for napari viewer, along with Skimage SLIC and Felzenszwalb for full m/z axis-based segmentation.

# Install - editable version
## bash/powershell
git clone https://github.com/Acrington-Stan/napari-msi-superpixels.git

cd napari-msi-superpixels

pip install -e .
